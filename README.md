# Моё расписание

Установимое веб-приложение (PWA) для расписания занятий и расчёта оплаты.

## Публикация через GitHub Pages
1. Открой **Settings → Pages**.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
4. Сайт будет доступен по адресу https://laofdfj.github.io/moe-raspisanie/.

## Файлы
- `index.html` — загрузчик приложения.
- `app.html.gz` — сжатая сборка приложения.
- `manifest.json` — параметры установки на телефон.
- `service-worker.js` — кеширование для офлайн-запуска.

Данные расписания хранятся локально в браузере. Для переноса между устройствами используйте резервную копию из приложения.
